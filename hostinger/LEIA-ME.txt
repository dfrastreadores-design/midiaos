====================================================================
  MÍDIA.OS / TV BRASÍLIA - GUIA DE DEPLOY NA HOSTINGER
====================================================================

CONTEÚDO DESTA PASTA:
1. .output/                  -> Pasta com o build de produção (SSR + Client).
2. hostinger.mjs             -> Arquivo de inicialização para o Node.js da Hostinger.
3. package.json              -> Metadados e dependências da aplicação.
4. .env.exemplo              -> Modelo de variáveis de ambiente.
5. schema_banco_de_dados.sql -> Todas as 151 migrações do banco em um único arquivo.

--------------------------------------------------------------------
PASSO 1: BANCO DE DADOS (PostgreSQL / Supabase)
--------------------------------------------------------------------
1. Abra o arquivo "schema_banco_de_dados.sql" e copie todo o código SQL.
2. Acesse o SQL Editor do seu projeto Supabase e execute o script.
3. Obtenha a URL do projeto e as Chaves de API (anon e service_role).

--------------------------------------------------------------------
PASSO 2: HOSPEDAGEM (hPanel da Hostinger)
--------------------------------------------------------------------
1. Compacte os seguintes itens desta pasta em um arquivo .zip:
   - Pasta .output
   - hostinger.mjs
   - package.json
2. Envie o .zip para a pasta "public_html" no Gerenciador de Arquivos da Hostinger e extraia.
3. No painel da Hostinger, vá em "Node.js" e configure:
   - Node.js Version: 20.x ou 22.x
   - Application Root: /public_html
   - Application Startup File: hostinger.mjs
4. Em Environment Variables (Variáveis de Ambiente), configure:
   PORT=3000
   NITRO_PORT=3000
   SUPABASE_URL=https://seu-projeto.supabase.co
   SUPABASE_PUBLISHABLE_KEY=sua_chave_anon_aqui
   SUPABASE_SERVICE_ROLE_KEY=sua_chave_service_role_aqui
   VITE_SUPABASE_URL=https://seu-projeto.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=sua_chave_anon_aqui
5. Inicie / Reinicie a aplicação.
