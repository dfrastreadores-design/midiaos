4. O QUE FAZER SE OCORRER ERRO
--------------------------------------------------------------------------------

1. Timeout no Editor do Supabase (Query Timeout):
   - Os arquivos 01 e 02 possuem ~300 KB cada. Se a conexão de rede oscilar e o
     navegador acusar timeout de interface, recarregue o editor e execute
     a query de verificação (Etapa 3) para confirmar se os objetos foram criados.
   - O PostgreSQL no Supabase aplica transações atômicas por comando ou bloco.

2. Erro de sintaxe ou objeto já existente:
   - Todos os arquivos utilizam "CREATE ... IF NOT EXISTS", "OR REPLACE" e
     "DROP ... IF EXISTS", projetados para tolerar reexecução.
   - Caso receba mensagem de erro específica, anote:
     a) O código do erro (ex.: 42P07, 23505).
     b) A linha informada no editor.
     c) O nome do objeto em conflito.

3. Falha na Etapa 3 ou Etapa 5:
   - Se a Etapa 3 apontar 'PENDENTE', NÃO execute a Etapa 4.
   - Se a Etapa 5 apontar 'PENDENTE', a Fase 1 precisará de ajuste cirúrgico antes
     da homologação funcional.
